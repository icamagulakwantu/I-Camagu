## Existing resolutions that require explicit review

The main branch currently pins `proxy-addr@2.0.8`, `body-parser@1.20.9`, `qs@6.16.1`, `source-map-js@1.2.2`, `fast-uri@3.1.9`, and `postcss-selector-parser@6.1.5`.

The `qs@6.16.1` resolution intentionally crosses Express's narrow `~6.15.1` range. It passed the then-current tests/build, but it is a dependency-resolution exception and should receive focused Express query-parsing regression coverage before being considered fully closed.
